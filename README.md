## Overview

Death and Taxes is a persistent-world PvPvE extraction RPG set in the continent of **Vaelmoor**.
Players are Zug'thar orcs — holding only a single volcano (**Vorgathul**) in a human kingdom —
who raid outward, extract home, study tomes, and build honor and renown.
